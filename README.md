# Fullstack task management with Material UI, nodejs, typescript & mongodb



![My Image](frontend/src/images/dash.png)



# Features:
##### - HOC (High Order Component)
##### - Admin & user Dasboard;
##### - React, Typescript, Material UI, 
##### - Redux toolkit, 
##### - Show & hide sidebar,
##### - Notification
##### - Assign task to a particular user,
##### - Forget & reset password by sending e-mail with reset link,
##### - Reset link is only valid for ten (10) mn.
##### - Login & register,
##### - Search & filter,
##### - Form validation (Formik & Yup)
##### - Pagination, Datagrid
##### - Responsiveness, etc
